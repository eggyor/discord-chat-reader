聊天記錄閱讀器 — 手機版（iPhone / iPad，可加入主畫面當 App 使用）
=====================================================================

這個資料夾裡「只有程式本身」，沒有任何聊天內容。
你的對話記錄只會存在你自己的手機裡，不會上傳到任何地方。

一、放到網路上（一次性，約 5 分鐘）
-----------------------------------
iOS 不能直接把本機的 HTML 檔案裝成 App，所以要先把這個資料夾放到任何一個
「靜態網站空間」（需要 https 網址），例如：
  • Netlify（把整個資料夾拖進 Netlify Drop 頁面）
  • Cloudflare Pages
  • GitHub Pages
把資料夾裡的所有檔案原樣上傳即可（index.html、sw.js、manifest.webmanifest、
xlsx.full.min.js、icons 資料夾，缺一不可）。上傳後會得到一個網址。
若網址是別人猜得到的，記得只放程式、不要放聊天檔案。

二、安裝到 iPhone
-----------------
1. 用 Safari 開啟上面的網址。
2. 點下方的分享按鈕（方框加向上箭頭）→「加入主畫面」。
3. 之後從主畫面圖示開啟，就是全螢幕、沒有網址列的 App。
   加入主畫面後 iOS 不會定期清除資料；沒加入的話，Safari 可能在 7 天沒使用後清掉。
   第一次開啟後程式會快取在手機裡，之後沒有網絡也能打開。

三、把記錄放進手機
-----------------
1. 在電腦版閱讀器載入你的 Excel，設好頭像、暱稱、書籤。
2. 電腦版「⚙ 設定」→「手機資料包」→ 匯出，得到「xxx.手機資料包.json」
   （含訊息、頭像、暱稱、書籤；不含附件，約 7MB 左右）。
3. 用 AirDrop 或 iCloud Drive 傳到手機的「檔案」App。
4. 手機 App 點「選擇檔案」→ 選那個 json。第一次匯入後記錄就存在手機裡，
   之後打開 App 會直接回到上次讀到的位置。
也可以直接選 Excel，但 8 萬筆的大檔在手機上可能因記憶體不足失敗，建議用資料包。

四、手機操作
-----------
• 左上角 ☰：書籤、設定、跳到日期、成員（點成員可換頭像 / 暱稱 / 顏色）。
• 上方搜尋框：輸入後按鍵盤的搜尋；點結果會跳到該訊息，下方出現「‹ 3/12 ›」可逐筆瀏覽。
• 長按訊息：加入書籤、複製文字／訊息編號／連結。
• 點回覆預覽：跳到原訊息；左下角「↩ 返回」回到剛才的位置。
• 右側細長捲動軸：拖曳可快速跳到記錄的任何位置。

五、手機和電腦之間同步書籤
------------------------
• 手機 → 電腦：手機 ☰ →「💾 資料檔」→「下載資料檔」，用分享選單存到「檔案」，
  再到電腦版「💾 資料檔」→「匯入資料檔」。
• 電腦 → 手機：重新匯出手機資料包，在手機重新匯入（書籤會合併，不會蓋掉手機上新增的）。

六、更新程式
-----------
把新檔案覆蓋到網站上，並把 sw.js 第一行的版本字串（chat-reader-v1）改成 v2、v3…，
手機重新開啟兩次後就會換成新版。
